# Spec board

Every spec in this repository, one card per folder. `/spec-board sync` rebuilds this
from the indexes; each phase command moves one card. The columns say which phase a
spec is in — a card's *health* is the `status:` in its `_index.md`, where `blocked`
means it is sitting on that column waiting for something.
