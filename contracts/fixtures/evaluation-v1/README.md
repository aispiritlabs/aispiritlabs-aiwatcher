# Pinned evaluation example

This is a local, synthetic contract fixture. `manifest.json` pins the real bytes
and sizes of the accompanying files. `fixture://` is a test reference scheme;
it is not a server route or a public artifact store. No existing instance or
production model label is touched by these files.

`responses.py` supplies three deterministic responses. `scorer.py` compares
Unicode strings exactly: no trimming, case conversion, model calls or numeric
coercion. An empty expected string is a valid answer. The `regression` split is
public example data, not held-out evidence of improvement. `generation.json`
illustrates the configuration artifact shape; no generation workflow is launched.

`identities.json` pins the variant/context hashes for compatibility. It is not
regenerated by the contract checker; an intentional fixture change must update
its artifact hashes and explicitly review the resulting identity change.
Schema/consumer regeneration never silently approves a new identity.

```sh
rtk cargo run -p aiwatcher-evaluation --example prepare -- contracts/fixtures/evaluation-v1/manifest.json
rtk proxy python3 scripts/check-evaluation-contract.py --write
```

Rust tests validate the semantic contract and identities. Python tests validate
the generated JSON Schema, SDK vocabulary, fixture bytes and scorer behavior.
The generated TypeScript consumer fixture must compile against the SDK types.
